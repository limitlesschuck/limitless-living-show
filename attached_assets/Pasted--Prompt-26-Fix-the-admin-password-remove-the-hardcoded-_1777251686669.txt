## Prompt 26

Fix the admin password — remove the hardcoded password from the seed file and update it to use an environment variable.

Step 1 — Update the seed file to use an environment variable for the admin password.

File to edit: artifacts/nextjs-app/prisma/seed.ts

Find this exact string:
  // Create super admin user
  const passwordHash = await bcrypt.hash("admin123", 12);

  const admin = await prisma.user.upsert({
    where: { email: "admin@limitlesslivingshow.com" },
    update: {},
    create: {
      email: "admin@limitlesslivingshow.com",
      name: "Admin",
      password: passwordHash,
      role: "super_admin",
    },
  });

Replace it with:
  // Create super admin user
  const adminPassword = process.env.ADMIN_PASSWORD ?? "changeme-set-ADMIN_PASSWORD-in-secrets";
  const passwordHash = await bcrypt.hash(adminPassword, 12);

  const admin = await prisma.user.upsert({
    where: { email: "admin@limitlesslivingshow.com" },
    update: { password: passwordHash },
    create: {
      email: "admin@limitlesslivingshow.com",
      name: "Admin",
      password: passwordHash,
      role: "super_admin",
    },
  });


Step 2 — Add ADMIN_PASSWORD to Replit Secrets.

In the Replit Secrets panel add:
- Key: ADMIN_PASSWORD
- Value: choose a strong password (minimum 12 characters, mix of letters numbers and symbols)

Do not use admin123.


Step 3 — Run the seed to update the password immediately in the dev database.

Run:
pnpm --filter @workspace/nextjs-app run db:seed

Confirm it prints "Created admin user: admin@limitlesslivingshow.com"


Step 4 — Clear all existing NextAuth sessions from the database.

Run:
cd artifacts/nextjs-app && node -e "
const { PrismaClient } = require('@prisma/client');
const p = new PrismaClient();
p.session.deleteMany({}).then(r => { console.log('Deleted sessions:', r.count); p.\$disconnect(); });
"


Verification: Confirm that:
1. seed.ts now uses process.env.ADMIN_PASSWORD with update: { password: passwordHash }
2. ADMIN_PASSWORD secret is set in Replit
3. Seed ran successfully
4. All sessions were deleted
5. Logging in with admin123 at /admin/login now fails
6. Logging in with the new ADMIN_PASSWORD succeeds
7. Deploy to production and confirm the same behaviour on limitlesslivingpodcast.com
